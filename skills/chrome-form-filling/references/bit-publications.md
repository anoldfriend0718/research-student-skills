# 学校论文填报案例的使用边界

这是学校专用表单的参考，不是通用认定政策。复用时必须读取当前学校的正式填报说明。

- 以 DOI、完整题名和来源唯一匹配论文，不按可变行号匹配。
- 区分卷号、期号、连续页码和文章编号。文章编号如何落入页面字段由当前系统要求决定。
- 区分 Received、Accepted、Online 和 Published 日期；采用哪一种必须有当前口径与原始证据。
- SCIE、EI、Scopus、中文核心及期刊等级分别核对，不互相推导。
- FWCI 与累计被引数不同。无权限、无显示、空值与数值 0 不同；缺失值按当前用户和系统规则处理。
- 遍历全部分页统计，核对分类是否重叠；暂存后刷新并复查记录集合、顺序及受保护字段。

本发布版未包含历史个人指标、完整论文清单或具体申报结果。
