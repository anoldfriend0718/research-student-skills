# Linux Codex部署与排障

以实际服务器环境和已执行检查为依据，交付可复现的配置、回退办法与分层验收结果。先区分目标：SSH中使用CLI、客户端离线后服务器独立运行、或Dot直接调用服务器。三者不能互相替代。

## 进入任务

1. 读取目标项目/设备的现有记录和授权，确认操作的是哪台主机。已有SSH别名、软件和代理优先复用；创建技能本身不授权重新部署服务器。
2. 检查当前安装和版本帮助，再核对[官方CLI文档](https://learn.chatgpt.com/docs/cli)。历史案例版本不是推荐最新版。更新、远程控制和后台命令均以目标版本`--help`为准，不硬套旧子命令。
3. 先确认目标环境有Python 3.6+，再执行[只读检查脚本](scripts/probe_linux.py)；没有符合版本的Python时采用[无Python基线检查](references/new-centos.md#不依赖python的首次检查)，不为采集基线临时安装解释器。宿主、桌面容器和实际Dot任务环境分别记录，不能互相代替。脚本不联网、不安装、不读取认证文件；服务名须显式传入。
4. 明确谁提供网络出口、登录回调在哪台机器、CLI后台是否已运行、是否必须关闭客户端仍可用。只读诊断不需要重新询问已有授权；必要变更沿用当前会话授权。

## 按目标执行

- **新CentOS首次部署：** 先读[新主机流程](references/new-centos.md)，确认真实发行版、内核、架构、权限和网络，再进入通用CLI流程。默认先完成CLI，不因历史案例而自动安装桌面、容器或代理。
- **CLI安装、独立联网、后台与SSH：** 读[CLI与网络流程](references/cli-network.md)。优先完成这条最短路径；CLI需求不需要桌面容器。
- **Dot个人电脑连接：** 只有用户需要Dot设备接入时，读[Dot接入与验收](references/dot-desktop.md)。CLI remote control、SSH成功和桌面登录均不等于Dot授权。
- **桌面容器的bwrap启动或只读保护异常：** 读[容器隔离排障与负向验收](references/bwrap-container.md)，依次核对依赖、seccomp、SELinux与真实写入边界。
- **旧CentOS兼容排查：** 读[匿名CentOS8验证案例](references/centos8-case.md)。这是2026-11-01的历史实测，先检查现状；不重复安装已工作的实例，不向新机器复制固定版本、路径、显示号或seccomp规则。

## 必须保留的操作边界

- 优先用户级安装、私有配置与精确服务变更。修改前保留原文件；不升级科研主机系统库来满足桌面依赖，不重启整机或中断科研作业来验证小改动。
- 密码和验证码由用户在官方页面或SSH客户端输入。不输出或复制登录token、cookie、私钥、代理订阅凭据。授权共享代理配置时仅经私密通道，保存权限限制为账户本人；技能包不包含这些数据。
- SSH主机key不一致先核验主机身份，不能删除known_hosts或关闭严格检查来消除报错。云端DNS失败、只读文件系统或工具不支持不能通过绕过访问控制解决。
- 保留TLS、包签名、SELinux及应用隔离。缺少bwrap或命名空间启动失败时，分清“命令未执行”和“命令执行失败”；修复依赖或使用工具正常审批路径，不全局降低权限。
- 每次重试要有新证据或单一可验证改动。相同失败连续两次且没有新线索，停止该路径并保留状态，报告阻塞；网络超时不能靠反复退出账号重登处理。
- 技能不自动发送Dot消息。只有用户明确授权向指定Dot发消息或执行验证时才发送。已有授权不重复索取；若设备切换会断开另一台设备，先完成其他准备，只对尚未获授权的替换影响确认。

## 交付与验收

逐项记录“已验证／仅配置／未验证”：安装版本与校验来源、认证、真实模型回复及退出码、CLI普通隔离工具执行、按需独立网络/后台会话、可选Dot调用。Dot还须区分设备授权、普通隔离工具启动、工具审批后的执行和宿主命令成功；审批后或宿主命令成功，不能反推普通隔离工具可用。HTTP 401/403仅证明部分连通性；登录成功不证明推理可用；服务active/enabled不证明开机或崩溃恢复。

“Windows关机后可用”需要先证明服务器代理和执行链不依赖Windows。没有实际关机就写“独立链路已验证，未做真实关机测试”；没有重启就不声称冷启动验证。后台tmux、CLI daemon、systemd与图形会话分别记录生命周期。

把实际版本、路径、备份和复现命令保存在目标设备的私有记录中，复读交付文件并保存必要校验值。最终简要说明可用入口、验证证据、运行条件及仍未完成的项目。
