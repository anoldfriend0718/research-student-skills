# CentOS 8历史验证案例（匿名化）

核验日期：2026-11-01。本页保留一次真实部署中的可迁移经验，设备名称、账号、连接地址、目录、随机标记及内部文件名不随公开包提供。历史版本不代表当前最新版或对所有CentOS的兼容承诺。

## 验证范围

宿主为CentOS Linux 8.1.1911、x86_64、内核4.18、glibc2.28。用户级Codex CLI 0.166.0采用官方Linux musl包，完成登录与真实模型调用。服务器独立代理在停止客户端转发后仍可支持模型请求；没有实际关闭Windows或重启整台服务器。

按该次用户需求另行安装官方ChatGPT 26.1027.30824，运行于rootless Podman中的Ubuntu24.04.5；没有升级宿主glibc。桌面采用独立持久home，未挂载整个科研主目录。桌面需求并不是安装CLI的前提，容器方案也不等于官方支持旧CentOS。

## 普通执行失败与修复

1. Dot能连接设备，但普通工具在执行检查命令前报`bwrap is unavailable`，工具启动退出101。经审批后执行成功不能证明普通隔离路径可用；宿主已安装bwrap也不能证明桌面容器有它。
2. 给持久镜像加入签名APT来源的bubblewrap0.9.0-1ubuntu0.3后，在无网络、无账号资料的测试容器追踪剩余失败：精确namespace clone与pivot_root受seccomp限制，相关挂载受SELinux限制。
3. 为该桌面创建独立SELinux域，保留当时容器基线与MCS约束，仅增加实际需要的挂载权限；专用seccomp仅加入观察到的调用，诊断ptrace不进入生产配置。没有改通用container_t、没有关闭SELinux或应用隔离。基线快照须在系统策略升级后复核，不能复制为通用安装规则。
4. 第一轮“命令能执行”仍不合格：只读profile内的测试文件可被追加。跟踪显示XFS-backed home的只读bind remount返回EACCES；补充专用域的filesystem remount权限后，写入才被拒绝，外层回读保持原文。

最终独立负向测试退出0；原Dot入口随后用默认工具一次执行成功，无提权、审批或重试，返回UID、glibc、bwrap版本及未知随机标记，标记经独立通道比对一致。实际NoNewPrivs为1、Seccomp为2，宿主SELinux保持Enforcing。更详细的方法见[隔离排障](bwrap-container.md)。

## 其他可迁移经验

- glibc优先读运行时版本，避免依赖`platform.libc_ver()`的启发式符号扫描；该次扫描曾误报较低版本。
- 旧运行时的系统调用过滤曾令新glibc无法正确回退。只有确认调用在该内核不存在及实际errno后才考虑专用兼容规则；内核升级后必须重新评估。
- 增加禁用HTTP/2与QUIC参数后，该次桌面工作区恢复。它是有观察依据的兼容试验，不说明所有联网超时均由同一原因造成。
- rootless容器更换时只让一个实例使用同一home，核对MCS标签、同步启动服务与preflight，保留旧实例和配置便于回退。
- oneshot服务active不等于应用持续running；独立网络、普通工具执行、模型回复和冷启动分别记录，不互相替代。
