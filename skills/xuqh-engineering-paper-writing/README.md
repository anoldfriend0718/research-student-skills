# 给学生的使用说明

这是课题组工程论文写作与修订 Skill。入口是 `SKILL.md`，`references/` 提供按任务读取的说明。它可以帮助初学者分步学习，也可以为熟手检查科学逻辑和润色；不会代替你的实验、模拟或对科研结果的确认。

## 从你现在的问题开始

不需要先跑一遍完整流程。提供当前材料、想解决的问题、允许修改的范围；已有主线、目标期刊或词数限制时一并说明。

你可以这样请求：

- **新手组织结果**：“我是第一次写论文，已有这些图和数据，但主线还没定。请先带我判断每张图回答什么问题，给我当前最少要完成的任务。”
- **保真准备稿件**：“把这份 Word 转成 Markdown，保留原文、图表、公式和引文；这一轮先不润色，列出转换没核实的部分。”
- **读文献和学语言**：“结合这几篇相关论文整理机制与证据、术语及常用表达，并说明哪些认识能支持我的论文、哪些不能直接迁移。”
- **提炼贡献**：“这是现有结果和相关文献卡。请区分已有贡献、可由结果支持的新解释和待验证的想法，帮我组织主线。”
- **熟手局部修改**：“只检查这一段的科学逻辑和英文表达，保留已成立的框架和比较口径。先给意见及候选改法，不写入文件。”
- **返修核对**：“对照这条审稿意见、当前正文和回复，检查修改声明是否真实、论证是否充分，再按我指定的范围修改。”

可以随时说“这一处请多解释一点”“直接给我可用版本”“只核查，不改写”。经验水平不是固定标签。

## 关于使用环境

这是可移植的 Skill 源文件夹。将完整文件夹接入你使用的、支持 Skills 的工具后，可用 `$xuqh-engineering-paper-writing` 明确调用；具体安装方式以该工具支持的方式为准。

普通段落建议不依赖专门软件。Word/PDF 的复杂公式、图表和引文恢复需要相应文档能力；如果当前环境不能完成，Skill 应说明限制，不能把摘要当作全文转换。知识库可以使用你自己的文件夹或已有系统，无需使用教师的个人目录。

分享包中的示例用于学习写作判断。你自己的论文数值、结论、贡献和验证状态仍必须来自自己的实际材料。使用前可先读 [来源与适用范围](references/source-notes.md)。

审稿人回复部分目前是初步版，优先检查回复与当前实稿是否一致；相关案例较少，将随实际返修任务逐步完善。
